# 2.76 寸 480×480 TFT MIPI 模组（ST7701）资料与示例

> 本仓库提供该模组的 **示例工程**，以及数据手册、规格与接口说明等资料，便于选型参考与集成开发。

## 产品概要

| 项目 | 说明 |
|:--|:--|
| 模组规格 | 2.76 英寸 **TFT**，分辨率 **480×480** |
| 接口 | **MIPI** |
| 驱动芯片 | **ST7701** |
| 规格标识 | 产品资料中常用 **`2.76-tft-480x480-mipi-st7701`** 表示本规格 |
